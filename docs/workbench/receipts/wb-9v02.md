- Method: the real `runWorkflow` over the real `createClaudeWorkflowHost`, through the host's fixture query seam (no SDK mock, no process, no network, no timer). The host's own `beforeDispatch` option is the barrier: the target attempt parks inside `await config.beforeDispatch?.()`. Every fixture query completes, so only the host or the runtime can keep one from running. The reading keeps every `beforeDispatch` entry, every SDK `query()` start attributed to the attempt whose entry preceded it, the fixture SDK's own call log, the `abortAgent` calls that reach the host while the target is parked, each host settlement, the row's final progress entry, the run status and the value the script received.
