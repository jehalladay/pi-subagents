- Oracle, pinned one breach at a time by R015-ORACLE and R016-ORACLE. A skip meets it only with no SDK start in any target attempt: a start of the original, of the replacement or of a later attempt each breaks it, while the origin agent's own start at resume does not. It also needs the target row's final progress entry present and marked skipped (a `done` row and a missing row each break it) and a null script value (an answer, `undefined`, `false`, `0` and the empty string each break it). A retry meets it only with no start of the original attempt, at most one start of the replacement attempt and none later, and no more replacement starts than replacement `beforeDispatch` entries (one replacement start with no replacement entry breaks it). The host settlements are retained in the reading and not judged: replacing them leaves each oracle verdict as it was.
