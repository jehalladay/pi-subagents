### Claims, each with the cases that pin it

The telemetry cases are in `test/workbench-mechanical-telemetry.test.ts` and the cost cases in `test/workbench-mechanical-cost-figures.test.ts`; each passes on this cut.

- EAT-R077, the bound. `ByteBoundedLog` keeps the newest items that fit its byte bound, drops an item larger than the bound without evicting, and counts every drop in items and bytes (R077-LOG-BOUND); a bound of 0, -1, 0.5, NaN, Infinity or 2^53 is refused with a RangeError, and 1 and Number.MAX_SAFE_INTEGER are accepted (R077-LOG-LIMIT). A run given `RunWorkflowOptions.telemetry` with `progressBytes` retains in `WorkflowRunResult.progress` the newest progress entries whose UTF-8 JSON bytes fit the bound, each unchanged, while `onProgress` is still handed every entry, and its `telemetry.progress` report counts what was offered, retained and dropped, each drop counted (R077-PROGRESS-FLOOD: 400 log rows holding two- and three-byte characters under 2048 bytes). Three gates that fail with 20000-byte outputs under an 8192-byte bound leave no retained entry holding that output, and their bytes are counted dropped (R077-PROVIDER-FLOOD). A log row larger than the bound on its own is dropped and evicts none of the entries before it (R077-OVERSIZED). Without the option the run retains every entry and carries no report (R077-UNSET). Each of 0, -1, 0.5, NaN, Infinity and 2^53 as `progressBytes` makes runWorkflow reject with a WorkflowRuntimeError whose message is "Workflow telemetry.progressBytes must be a positive integer." and dispatch nothing, and Number.MAX_SAFE_INTEGER is accepted (R077-INVALID).
- EAT-R078, the stages. Under the option the run hands `telemetry.onStage` one record per measured stage, each with its stage name, the call's kind and position, a duration on the monotonic clock (`performance.now()`), its own bytes and, when the provider reported one, its own id. With the wall clock rolled back 60 s inside the call: an agent's sdk stage is no shorter than its host call and carries the answer's session id (R078-SDK-ROLLBACK); a gate the runtime runs through `host.runGate` reports a gate stage no shorter than the call, with its output's bytes and no id (R078-GATE-ROLLBACK); a `forge.gate.status` node's stage is no shorter than its host call and carries the operation id of its answer (R078-NODE-ROLLBACK); a nested `workflow()` load is no shorter than its `host.loadWorkflow` call, with the script's bytes, and a refused or a thrown load reports its message's bytes (R078-LOAD-ROLLBACK); an agent queued on a one-query budget reports an admission stage of its lease's monotonic wait, at least 30 ms, with 0 bytes (R078-ADMISSION-ROLLBACK). Each sdk stage carries its own answer's bytes and its own session id, and an agent whose host reports no session carries none (R078-NATIVE-IDS); a failed answer reports its error's bytes and session id, and a thrown host call the thrown message's bytes (R078-FAILED-SDK). A node answer with no native evidence, and a node call that rejects, report their bytes and no id (R078-NODE-NO-NATIVE); a non-read node refused because its dispatched journal row could not be written reports no node stage (R078-NODE-NOT-DISPATCHED); a gate call that throws reports no gate stage and adds no second sdk record (R078-GATE-THROWS). An `onStage` that throws leaves the run's status and value as they are without the option (R078-THROWING-REPORT). The stage names are admission, load, sdk, gate and node (R078-STAGE-NAMES). On the production path too, an agent's and a node's progress row now measures `durationMs` on the monotonic clock, rounded to whole milliseconds: with the wall clock rolled back mid-call it is not negative (R078-SDK-ROLLBACK and R078-NODE-ROLLBACK for done rows, R078-NODE-NOT-DISPATCHED for a refused node's error row). On trunk it is a Date.now delta: restoring that expression (battery members S11 and S12) reads -60000 ms on the agent's and the node's done rows under the same rollback.
- EAT-R079, the load journey, fixture leg. `runLoadJourney` (`qa/workbench/mwi-multiworkflow-load.mjs`) runs a one-run baseline phase and a load phase of 3 simultaneous runs plus one run cancelled while its agent is queued, each phase on its own HostAdmission (2 SDK queries, 5 child processes, 1 Forge operation) and its own counting fixture host. R079-JOURNEY wraps the runWorkflow it hands the journey to observe each phase independently and pins: every peak, the queue-wait summary and the progress sums the record carries equal what the test observed of the same phase; the load phase's SDK peak is the shared limit 2, above the one-workflow limit 1, while the baseline's is 1; the budget's own peaks stay within its limits; each completed run dropped progress past its 4096-byte bound; the cancelled run ends killed and nothing of it is dispatched; the budget's slots are back at rest after each phase; the memory figures are positive safe integers; and the record's node, package and ref are this checkout's (`process.version`, `package.json`, `git rev-parse HEAD`, and whether `git status --porcelain` is empty).
- EAT-R164, the cost judges. `costTableFindings` (`qa/workbench/mwi-cost-figures.mjs`) reads a receipt's `mwi-cost` blocks: a table whose four stage rows (pack, install, admission, gate) each carry date, host, command, samples, pin and value, well formed, has no finding (R164-ROW-COMPLETE); a row without any one of the six fields is refused as field-missing naming it (R164-ROW-FIELDS); a malformed date, sample size, pin or value, an empty, an unknown, a repeated and a malformed field are each refused by their own rule (R164-ROW-FORMS); a `not run: <why>` row needs no field, and one without its reason is refused (R164-NOT-RUN); an October median copied into a row as the current install cost, the 398 s of the 2026-10-20 report or the 7 s of the 2026-11-02 report, is refused, while a fresh 7012 ms is not (R164-OCTOBER-AS-CURRENT, the requirement's mutant); a missing, repeated or unknown stage row, and a receipt with no table, are refused (R164-TABLE-STAGES). `historicalFigureFindings` flags a rendered line holding either October figure, in the pinned spellings, beside a present-tense cost verb when the line does not name that figure's own report date (R164-CENSUS-FLAGS), and stays quiet on the history forms and the near figures R164-CENSUS-QUIET lists; it reads list items, table rows and fenced lines (R164-CENSUS-RENDERED). `programCensusFiles` lists every markdown file under `docs/workbench/programs/` and every per-bead receipt that carries an mwi-release block (R164-CENSUS-FILES); no file it lists states an October figure as a current cost (R164-CENSUS-TREE); and this receipt's cost table below has no finding (R164-RECEIPT-TABLE).
