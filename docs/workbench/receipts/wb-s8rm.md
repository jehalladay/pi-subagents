# wb-s8rm: [MWI-source] Admit writes only against host-owned immutable source identity

## 2026-11-06 receipt: Pi-local write admission for EAT-R022..EAT-R027, not wired yet and explicitly partial (machine seat ws-01, base 814dcdd)

- Surface: `src/workbench/source-admission.ts`, a new module, and `test/workbench-mechanical-source-admission.test.ts`, 40 cases on real Git repositories built in tracked scratch. Requirement text: EAT-R022..EAT-R027 of `docs/workbench/programs/mechanical-workflows-interop-2026-11-04/triage/requirements/ATOMIC-REQUIREMENTS.md` at pi-subagents master `0b25e14e` (the triage tree stays master-only); the suite's header quotes each statement, acceptance and adversarial mutant.
- The seam: `admitSourceWrite(request, host, dispatch)` calls the write-capable dispatch at most once, with the only grant it mints, after these checks in order. The workspace path must be absolute, resolve by realpath inside the host's authorized root (judged by `path.relative`, never by a string prefix) and be the root of its own Git worktree (EAT-R023). The host then measures the source identity itself: the canonical root, read through the repository its own `.git` names; the HEAD commit and tree; no tracked, staged or untracked edit in `git status`; no index entry flagged assume-unchanged or skip-worktree; and the SHA-256 of the gate manifest's bytes, which must stay inside the workspace (EAT-R022, EAT-R026). An attestation minted by the host's `WriteBoundaryAuthority` for exactly that workspace and identity is required, and a JSON policy's `allowWrites: true` only asks for writes (EAT-R027). One `WriterLeases` lease per canonical root is taken, and only the admission that took it releases it (EAT-R024). After the host's admission wait the identity is measured again and the attestation read again, immediately before the dispatch (EAT-R025).
- The module launches nothing and reads no environment: Git is read through the host's `SourceGitReader`, handed the argv the module builds (`--no-optional-locks`, `core.fsmonitor` and `core.untrackedCache` pinned off). The suite's reader runs real git with the repository-locating variables removed, and R022-MISDIRECTED-GIT shows a reader pointed at another repository refusing. No new contract literal is minted.
- Per requirement, by case id:
  - EAT-R022: R022-TRACKED, R022-STAGED and R022-UNTRACKED refuse `dirty-base`, each edit counted in its own column; R022-ASSUME-UNCHANGED and R022-SKIP-WORKTREE refuse `source-unmeasurable` while `git status` reads clean; R022-MISDIRECTED-GIT refuses `source-unmeasurable`; R022-CLEAN dispatches once against the commit and tree git reports; R022-IGNORED dispatches, since an ignored build file is not an edit.
  - EAT-R023: R023-WRONG, R023-SIBLING (a `-sibling` directory whose path starts with the root's) and R023-ESCAPE (a symlink inside the root) refuse `workspace-outside-root` although the operator attested each of those workspaces; R023-SUBDIR refuses `workspace-not-worktree-root`; R023-RELATIVE refuses `malformed-request`; R023-ALIAS-INSIDE dispatches against the canonical root; R023-CONFINE reads `confineWorkspace` directly.
  - EAT-R024: R024-ALIAS (a symlink alias and a dot spelling refuse `writer-held` while one invocation writes), R024-CANCEL-OWN (a refused invocation's cancellation keeps the holder's lease, the holder's cancellation releases it, and the next admission dispatches) and R024-STALE (a released lease never releases the next holder's).
  - EAT-R025: R025-COMMIT, R025-AMEND (a new commit with the same tree), R025-GATE (gate manifest bytes, `git status` still clean) and R025-TRACKED change the source while the admission is parked, and each refuses `source-changed` with the lease released; R025-CONTROL dispatches once.
  - EAT-R026: R026-IDENTITY (same root, commit, tree and clean status; the gate manifest's `sha256` equals the SHA-256 of the bytes and the identity digest changes), R026-STALE (the old attestation refuses `attestation-stale`, and one for the new identity dispatches) and R026-UNAVAILABLE (a missing manifest, a `../` path and a symlink out of the workspace refuse `gate-manifest-unavailable`).
  - EAT-R027: R027-ABSENT (`allowWrites: true` with no attestation refuses `attestation-absent` and nothing is dispatched), R027-POLICY-COPY, R027-FORGED and R027-FOREIGN-AUTHORITY (a copy in the JSON policy, an equal-shaped copy in the host's slot and another authority's attestation are not attestations), R027-OTHER-WORKSPACE (`attestation-other-workspace`), R027-NOT-REQUESTED, R027-WITHDRAWN (withdrawn while the admission waits), R027-UNMEASURED (the authority attests only an identity the host measured) and R027-ATTESTED (a frozen grant naming the operator).
  - Lifecycle: GEN-PRE-ABORTED, GEN-WAIT-REFUSED, GEN-DISPATCH-THROWS, GEN-MALFORMED and GEN-READER-FAILS (a reader that throws or answers with no Buffer is a refusal, never a rejection).
- Explicitly partial: the seam is not wired yet. `workflow_execute` still refuses a function definition (`src/workbench/execute-tool.ts`, `unsupported-definition-kind`), and the dispatch bead (EAT-R032..EAT-R035, gate PI-FUNCTION-REGISTERED, external MW-HOST) composes it and supplies the host's reader.
