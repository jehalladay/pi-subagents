The artifact must lie strictly inside the root, be a regular file opened without following a final link, and have bytes whose SHA-256 equals the pin.

The loader then runs once, with the reviewed entry and the bytes just measured. The reviewed export name, never a descriptor string, is read from what it returns. The boundary never calls the export, so it makes no provider call and has no effect beyond reading the two files.
