## Reading the matrix

- **L0** is the only tier with a verdict; `PASS` means the row is traceable, non-laundering and executable as written; `COND(F-xx)` names the fix items in `REQUIREMENTS-AUDIT.md` that must land before the row is filed or implemented. No row is `FAIL` at L0: the compiled statements themselves are sound; the conditions are mapping, custody and gate defects.
- **BLOCKED** cells: R345 (every cell, G-RULING), R351/R352 L7 (G-PTY), R367 criterion 4 (amendment of the landed wb-jwc.7 custody pin), R387 C120 leg (G-EXTERNAL-ENFORCEMENT). A BLOCKED cell is recorded as BLOCKED with its artifact in the acceptance run; it is never recorded as PASS or silently skipped.
- **A\*(G-...)** cells run only against the real artifact the gate names; a helper, fixture or injected callback does not discharge them (r-ops/r-platform contract: 'Direct injected callbacks are V3, never native proof').
- **S** cells: L4/L9 on doc-only REPRESENTATION rows (R327, R339, R376, R386 partial) — the unit is the generated-text drift test, and branch coverage of prose is structurally meaningless; L2 on the V1 interop rows (R337, R338, R340) because no registered caller exists at the pin (C119) — the registered repetition is owed at wiring (EAT-R265 lineage).
- Every `A`/`A*` maps to the named probe/test/qa oracle in the requirement's own criteria (all 81 path references and 52 bare probe names resolve under `probes/` or the pin — verified by this audit).
- Residual queue outside this matrix: the 13 uncovered defect claims (F-01), the 14 prose-only deferrals (F-13) and every `DEFERRED_FOR_RANGE_CAPACITY` table row in req-r-ops.md / req-r-platform.md need follow-on IDs (EAT-R391+) before they can have a row here.
