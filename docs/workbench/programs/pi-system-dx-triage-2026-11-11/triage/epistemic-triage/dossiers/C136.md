# C136 — Claude-backend replay silently never happens in repositories over 2,000 paths

- **Claim:** C136 (source JOURNAL-003, journal family) · **Axis/grade:** gap / ESTABLISHED
- **Pin:** ce180d82 (worktree `pin-ce180d82`), graded 2026-11-11

## Defect
Under the Claude backend `resumeFromRunId` never replays a recorded agent answer in a repository with more than 2,000 Git-visible paths (or outside Git): the workspace survey returns "unknown", the host declines replay outright, and nothing shipped documents the cap.

## Reproduction
```
PIN=.../pin-ce180d82  PJ=.../probes/journal
cd $PIN && ./node_modules/.bin/vitest run --config $PJ/vitest.probe.config.mts $PJ/p14-replay-cap.probe.ts   # -> out/p14-replay-cap.json
cd $PIN && ./node_modules/.bin/vitest run --config $PJ/vitest.probe.config.mts $PJ/p08-silent-decline.probe.ts # -> out/p08-nonrepo.json
```
Observed: control at 1,990 git-visible paths -> `recordedReadings.source {state:measured}`, summary "... 1 replayed from wf_3b4e96b27ee1", `replayed true`. Trial at 2,001 paths, same script, same args, untouched workspace -> `source {state:'unknown', reason:'source-candidate-unmeasured'}`, resume line still promises "1 recorded agent call available to replay", summary "completed — 0/4 agents", `replayed false`. Outside a Git repository: same promising resume line, `result 'null'`.

Code anchors: src/index.ts:360-400 `workspaceCandidateBasis` (`git ls-files --cached --others --exclude-standard`; `if (names.length > 2_000 ...) return unavailable`; also any non-regular file or symlink, >32 MiB, 2 MiB ls-files buffer, 5 s git timeout — those four code-read, not run); src/workbench/claude-host.ts:350 `replaySafe`; src/workflow/runtime.ts:924 `prefixIntact`. Documentation absence: greps over README.md, docs/workflows.md, docs/workbench/*.md find no statement of the cap; test/workbench-replay-dependencies-wiring.test.ts header lists "more than 2000 paths or 32 MiB" under NOT CLAIMED. The pin itself has 1,346 tracked files.

## Cost
Every Claude-backend user in a mid-size or larger repository (and anyone outside Git, or with one committed symlink): each resume re-pays every agent; for the 40-agent audit src/workflow/journal.ts:6-9 uses as its motivating case that is the whole cost of the run, every time.

## Cure options
1. **Primary (investigator):** hash `git ls-files -s` output plus `git status --porcelain=v2` bytes (or tree oid + dirty-file digests) instead of reading every Git-visible file, so repository size no longer disables replay.
2. Where a reading is unknown, say so in the launch text instead of promising replay (ties C137 / JOURNAL-004), and document the conditions in docs/workflows.md.
3. Interim: make the 2,000-path bound a setting with the current value as default, so large-repo operators can opt in at a measured cost.
