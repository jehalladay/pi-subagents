# C034 — A symlinked $HOME kills every detached launch

- **Claim:** C034 (source DETACHED-002, detached family) · **Axis/grade:** DX / ESTABLISHED
- **Pin:** ce180d82 (worktree `pin-ce180d82`), graded 2026-11-11

## Defect
On any host whose `$HOME` contains a symlink (standard Amazon cloud-desktop layout `/home/<user>` -> `/local/home/<user>`), every `workflow_detached` launch and every `workflow_execute hostMode:detached` refuses with `Authorization: unsafe detached directory ancestor.` — because the launch directory `join(getAgentDir(),'workbench-detached')` inherits the symlinked home and `ancestors()` lstat-refuses symlink ancestors. The message names neither the offending ancestor nor any remediation (`PI_CODING_AGENT_DIR` to a realpath works but is undocumented).

## Reproduction
Probe P8 (probes/detached):
```
ls -ld /home/jehallad   # lrwxrwxrwx ... /home/jehallad -> /local/home/jehallad
# os.homedir() -> /home/jehallad
# launchDetachedWorkflow({directory:'/home/jehallad/.pi/agent/workbench-detached',...})
#   -> throws 'Authorization: unsafe detached directory ancestor.' ; nothing written
```
Code anchors: src/index.ts:2918 `directory = join(getAgentDir(),'workbench-detached')`; src/agent-dir.ts:53 `join(homedir(),'.pi','agent')`; src/workbench/hosts/local-detached.ts:186-194 `ancestors()` refuses `stat.isSymbolicLink()`.

## Cost
100% launch failure for the whole detached feature on symlinked-home fleets; the terse message gives no path to diagnosis, so operators conclude the feature is broken.

## Cure options
1. **Primary (investigator):** `realpathSync` the agent dir (or the `directory` argument) before `ancestors()`, and have `ancestors()` name the failing ancestor and the `PI_CODING_AGENT_DIR` workaround in its message.
2. Alternative: keep the symlink refusal for caller-supplied directories but exempt (or pre-resolve) the extension's own computed default, which the user never chose.
3. Docs stopgap: document the symlinked-home failure and the `PI_CODING_AGENT_DIR=<realpath>` workaround in README/docs/workflows.md.

## Related
C043 (DETACHED-011) is the adjacent environment trap (TMPDIR > 62 bytes with no private runtime base). Together they make detached launch fail out-of-the-box on common fleet layouts.
