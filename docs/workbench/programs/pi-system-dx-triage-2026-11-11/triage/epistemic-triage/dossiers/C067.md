# C067 — 22 KB SubagentWorkflow tool description in every mode

- **Claim:** C067 (source EXECUTE-018, execute family; SAME_ORIGIN NODE-RPC-008) · **Axis/grade:** QoL / ESTABLISHED
- **Pin:** ce180d82 (worktree `pin-ce180d82`), graded 2026-11-11

## Defect
The SubagentWorkflow description is 22,095 bytes (about 5.5k tokens at 4 bytes/token) and is sent in full in every mode: `toolDescriptionMode: "compact"` shrinks only the Agent tool. It is 52% of the 42,339-byte tool surface a Workbench session registers; the only way to shed it is to switch workflows off entirely.

## Reproduction
```
cd pin-ce180d82 && ./node_modules/.bin/vitest run --config ../probes/execute/vitest.probe.config.ts execute-extra
# -> probes/execute/results/execute-extra.json#L_tokenCost
```
Observed: full `{totalBytes:42339, SubagentWorkflow:{descriptionBytes:22095, schemaBytes:1228}, Agent:{descriptionBytes:6368}}`; compact `{totalBytes:37485, SubagentWorkflow:{descriptionBytes:22095}, Agent:{descriptionBytes:1514}}`. Corroboration (SAME_ORIGIN NODE-RPC-008): 20,672 chars / 3,114 words / ~5.2K tokens measured at probes/node-rpc/probe4-description-cost.out.txt.

Code anchors: src/index.ts:3301 `description: renderToolDescriptionTemplate(fullWorkflowToolDescription)` (no mode branch); :1620-1721 (compact/custom apply to the Agent description only). Docs: README.md:694 scopes `toolDescriptionMode` to "which Agent tool description the LLM sees … for small/local models where tool-spec tokens are expensive"; README.md:688 offers `workflowsEnabled` off as the way it "costs no tool-spec context".

## Cost
Every session with workflows enabled (the default) pays ~5.5k tokens of tool spec per request (cached or not); small/local-model users who chose compact mode for exactly this reason still pay it.

## Cure options
1. **Primary (investigator):** ship a compact SubagentWorkflow description (API list, caps, one worked example; patterns moved to docs/workflows.md) selected by `toolDescriptionMode` or a dedicated setting.
2. Alternative: split rarely-used sections (resume, node(), reconcile guidance) into on-demand docs reachable via a `workflow_catalog`/help surface and keep the description to the launch contract.
3. Honesty fix while unfixed: README.md:694 should say compact mode does not apply to SubagentWorkflow.

## Related
