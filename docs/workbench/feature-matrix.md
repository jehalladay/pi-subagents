docs/workbench/17-packaging-and-operations.md § "Versioning / distribution" requires: "Release docs include feature matrix with status (not claimed based only on source commit)."

This matrix implements that requirement. Measurement date: 2026-10-15. Trunk: branch `workbench/implementation-program` (HEAD at this ledger export: 1e4102f). Three features that landed on 2026-10-15 after the first measurement pass (wb-zmd at e830ac2, wb-0kg.1 at ee8bde0, wb-h8f.1 at 1e4102f) were re-measured at 1e4102f. A second same-day reconcile pass at 1b735c8 re-measured wb-6ze.9 (landed e6c22a2), wb-69g.6 (landed e7bcadd) and wb-9x5.4 (landed 1b735c8); those rows cite their landing merges. Statuses were assigned read-only from what exists on trunk (named test files), docs/workbench/TRACEABILITY.md sections, and bead close receipts naming gate ids; no status in this document is claimed from a source commit alone.

Column note: bead statuses cited in the Status, Evidence and Caveats columns are as of the Beads ledger export at 2026-10-15. An in_progress bead whose delivery exists only on a machine branch (machine/flywheel/...) is still "not landed": nothing counts as landed, and no landed-gated claim rests on it, until the work is on trunk (workbench/implementation-program). Machine-branch deliveries are therefore cited only in caveats, never as landed evidence.

## Status legend

Status vocabulary (exactly one per row):

- landed-gated: the feature's code AND tests exist on trunk (branch workbench/implementation-program) and a TRACEABILITY.md section or bead close receipt names a passing gate for it.
- partial: some slices landed-gated, others open/in-progress (both halves named in the row).
- in-progress: beads in_progress but nothing landed for the feature yet.
- planned: beads open only.
- not-started: no bead and no code.

A status is never inferred from a source commit alone: landed-gated requires a test file that can be named plus a TRACEABILITY section or a closed bead with a gate receipt. When in doubt, the weaker status was chosen and the row says why.
